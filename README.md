# MIRROR CASE — entrance prototype

AIパートナーと遊ぶ協力型推理ゲームの、トップ入口だけを実装した版です。
ゲーム本編の仕様・事件データは含みません。

## デザイン意図

墨色に近い深緑、紙色の活字、くすんだ真鍮色を使用。
大きなセリフ体のタイトルと、線で区切ったメニューを中心にした静かなタイトル画面です。
鏡は二重の輪郭で「ふたりの視点」を示す幾何学的なSVG。夜の奥行きはありますが、ホラー表現は使いません。
常時アニメーション・映像・外部画像・外部フォントはありません。

## ファイル

| ファイル | 役割 |
| --- | --- |
| `index.html` | タイトル、4つの入口、装飾SVG、共通ダイアログ |
| `styles.css` | 色・書体・配置・レスポンシブ対応 |
| `app.js` | 入口ダイアログ、文字サイズ設定、既存セーブの有無確認 |
| `vercel.json` | 既存の静的配信設定（変更なし） |

HTML / CSS / JavaScriptだけで動きます。ビルド・npm install・API・DB・ログインは不要です。
`index.html`を直接開いて確認できます。文字サイズの保存挙動はブラウザや開き方により異なるため、継続運用時は静的HTTP配信を使ってください。

```sh
python3 -m http.server 8000
```

`http://localhost:8000`を開きます。VercelではFramework PresetをOther、ビルドコマンドなし、プロジェクトルートを配信対象にします。

## 今できること

- 「事件をはじめる」「つづきから」「事件記録」で、その入口の準備状況を表示。
- 「設定」で文字サイズを標準／大きめに変更し、このブラウザへ保存。
- Tabで操作、Escまたは閉じるボタンでダイアログを閉じ、開いたボタンにフォーカスを戻す。
- スマホでは1列の操作メニュー、鏡は小さな背景へ配置変更。

## 保存の扱い

- 既存の`mirror-case:app:v1`は読み取りのみ。`activeCase`がある場合も、ゲーム本編の再開はしません。
- 起動時の空セーブ作成は廃止。事件の作成・削除・書き換えは行いません。
- 文字サイズだけ`mirror-case:ui:v1`に`{ version: 1, textSize: 'standard' | 'large' }`で保存。
- 保存禁止・破損データ時も入口は動作。文字サイズを保存できない場合は、その旨を設定内に表示。

## 将来の拡張ポイント

1. `app.js`の`actions`が4つの接続点です。`new-case`、`resume`、`archive`、`settings`の処理を、本編の画面遷移に差し替えられます。
2. 保存形式と移行処理は、本編の仕様が決まってから別ファイルに分離します。既存のキーは不用意に上書きしないでください。
3. 色・フォントは`styles.css`冒頭の変数、入口文言は`index.html`と`actions`を編集します。
4. 鏡のSVGは装飾専用です。事件の舞台・手掛かり・ルールは定義していません。

未実装：事件生成、カード、マップ、推理提出、AI接続、ゲーム本編、記録の保存。
