# MIRROR CASE — entrance prototype

AIパートナーと遊ぶ協力型推理ゲームの、トップ入口とMIRROR ROOMへの記帳を実装した版です。
ゲーム本編の仕様・事件データは含みません。

## デザイン意図

墨色に近い深緑、紙色の活字、くすんだ真鍮色を使用。
大きなセリフ体のタイトルと、線で区切ったメニューを中心にした静かなタイトル画面です。
日本語は説明・メニュー・登録簿・入力した名前まで明朝体を中心に統一し、古い本の活字に寄せています。端末内の游明朝／ヒラギノ明朝／Noto Serif系を使うため、端末により書体は異なります。
真鍮の鏡と、暖かく灯る隣室を映す写真的なキービジュアルを画面全体に配置。左の暗い壁面へ既存のタイトル・メニューを重ねます。
光・素材・奥行きは画像で表現し、CSSは可読性用の薄い陰影だけに使用。常時アニメーション・映像・外部フォントはありません。画像は同梱WebPです。

## ファイル

| ファイル | 役割 |
| --- | --- |
| `index.html` | タイトル、4つの入口、背景画像、共通ダイアログ |
| `styles.css` | 色・書体・配置・レスポンシブ対応 |
| `app.js` | 記帳・名前変更、入口ダイアログ、文字サイズ設定、既存セーブの有無確認 |
| `tests/registration.test.cjs` | DOMイベントのテスト用ハーネスによる登録・保存の回帰確認 |
| `assets/mirror-study.webp` | 映画的な夜の書斎のキービジュアル |
| `vercel.json` | 既存の静的配信設定（変更なし） |

HTML / CSS / JavaScriptだけで動きます。ビルド・npm install・API・DB・ログインは不要です。
`index.html`を直接開いて確認できます。文字サイズの保存挙動はブラウザや開き方により異なるため、継続運用時は静的HTTP配信を使ってください。

```sh
python3 -m http.server 8000
```

`http://localhost:8000`を開きます。VercelではFramework PresetをOther、ビルドコマンドなし、プロジェクトルートを配信対象にします。

## 今できること

- 初回の「事件をはじめる」で古い調査登録簿を開き、探偵名（AIパートナー）と助手名を記帳。
- 保存後に小さな「記帳済」の印を表示。「最初のCASEを受け取る」は準備中の案内で止まります。
- 登録済みなら記帳を省略。入口に二人の名前を控えめに表示し、「設定」から変更できます。
- 「つづきから」「事件記録」で、その入口の準備状況を表示。
- 「設定」で文字サイズを標準／大きめに変更し、このブラウザへ保存。
- Tabで操作、Escまたは閉じるボタンでダイアログを閉じ、開いたボタンにフォーカスを戻す。
- スマホでは1列の操作メニュー。同じキービジュアルの表示位置と陰影を調整。

## 保存の扱い

- 既存の`mirror-case:app:v1`は読み取りのみ。`activeCase`がある場合も、ゲーム本編の再開はしません。
- 起動時の空セーブ作成は廃止。事件の作成・削除・書き換えは行いません。
- 記帳は専用キー`mirror-case:pair:v1`に`{ version: 1, detectiveName: 'Nay', assistantName: 'なや' }`で保存。名前は前後の空白を除き各1〜40文字です。
- 保存に失敗した場合は登録完了に進まず、入力を残して再試行できます。不正な保存データは自動削除せず、明示的に記帳したときだけ上書きします。
- 文字サイズは`mirror-case:ui:v1`に`{ version: 1, textSize: 'standard' | 'large' }`で保存。
- 保存禁止・破損データ時も入口は動作。文字サイズを保存できない場合は、その旨を設定内に表示。
- localStorageはブラウザ・オリジンごとです。異なるPreview URL間で記帳は共有されません。

## 将来の拡張ポイント

1. `app.js`の`actions`が4つの接続点です。`new-case`、`resume`、`archive`、`settings`の処理を、本編の画面遷移に差し替えられます。
2. 保存形式と移行処理は、本編の仕様が決まってから別ファイルに分離します。既存のキーは不用意に上書きしないでください。
3. 色・フォントは`styles.css`冒頭の変数、入口文言は`index.html`と`actions`を編集します。
4. キービジュアルは雰囲気を伝える背景です。事件の舞台・手掛かり・ルールは定義していません。

未実装：事件生成、カード、マップ、推理提出、AI接続、ゲーム本編、記録の保存。

## 検証の範囲

```sh
node --check app.js
node --test tests/registration.test.cjs
git diff --check
```

テストは実際の`app.js`を最小限のDOM・localStorageハーネスで実行します。初回登録、再訪、名前変更、入力検証、保存不可、不正データ、別タブ同期、既存セーブの非破壊と既存メニューを確認します。
実ブラウザの描画・ネイティブ入力検証・フォーカストラップを検証するものではありません。これらとスマホ実機の表示はPreviewでの確認対象です。
